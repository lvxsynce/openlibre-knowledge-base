# OpenLibre Knowledge Base (ТСПУ / DPI / Обход блокировок)

Структурированная база знаний и долговременная память для нейросетей, собранная на основе анализа **230 965 реальных сообщений** из супергруппы `openlibrecommunity`.

Вся хронология проанализирована через **Gemini 2.5 Flash** с использованием RAG-памяти: скрипт фиксирует не просто статический снимок, а эволюцию решений — что работало, когда и почему сломалось, и какие обходные пути были найдены участниками.

## Что внутри

- **[status_report.md](status_report.md)** — Главный сводный отчет:
  * 🟢 **РАБОТАЕТ** (актуальные конфиги, параметры, устойчивые связки).
  * 🔴 **НЕ РАБОТАЕТ** (что заблокировано ТСПУ, сбросы TCP RST, бан TLS фингерпринтов).
  * 🟡 **ПОД ВОПРОСОМ** (плавающие результаты, решения на стадии тестирования).
  * **Хронология эволюции:** для каждой из 309 технологий отслеживается вся история изменений статусов (от ранних версий до сегодняшнего дня).
- **[index_catalog.md](index_catalog.md)** — Реестр-память для быстрого поиска LLM:
  * Таблица по всем 695 пачкам сообщений с темами, кратким саммари и ключевыми технологиями.
  * Реестр важных находок: прямые ссылки на рабочие конфиги, дампы и инсайты по ТСПУ.
- **[chunks/](chunks/)** — Нарезанный очищенный датасет (695 файлов Markdown) с локальными якорями `chunk_XXXX.md#msg_YYYY` для перехода в первоисточник в один клик.

## Как это устроено

```text
result.json (230k сообщений)
         ↓
  [preprocess.py]  →  фильтрация служебного шума, спама и односложных реплик
         ↓
  [chunks/ (695 md)]  →  разбивка на порции по ~300 сообщений с локальными якорями
         ↓
 [orchestrator.py]  ↔  Gemini 2.5 Flash + динамический RAG текущего состояния
         ↓
  [build_reports.py]  →  status_report.md  +  index_catalog.md
```

## Как запустить анализ самому

### Требования

- Python 3.10+
- Доступ к OpenAI-совместимому API с моделью `gemini-2.5-flash`

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск полного цикла

1. **Предобработка сырого экспорта Telegram:**
   ```bash
   python preprocess.py
   ```
2. **Запуск LLM-оркестратора с RAG-памятью:**
   ```bash
   python orchestrator.py
   ```
3. **Сборка итоговых отчетов:**
   ```bash
   python build_reports.py
   ```
