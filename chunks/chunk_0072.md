Всем привет, может кто подсказать, способ Yandex API Gateway (Reverse Proxy) из статьи https://habr.com/ru/articles/1027276/ еще рабочий? 
  Поднял по инструкции — домен на Cloudflare, серт LE через YC Cert Manager,
  gateway с openapi-спекой, бэкенд с nginx+Xray на VPS вне РФ.

  Уперся в архитектурное ограничение API Gateway: он буферит response body до
  EOF, не пропуская streaming. Потестил все варианты:
  - VLESS+WS: gateway режет 405 Method Not Allowed на Connection:Upgrade
  - VLESS+httpupgrade: то же самое
  - VLESS+gRPC: 503 "Parse Error: Expected HTTP/" (gateway HTTP/1.1 в backend,
    Xray gRPC требует HTTP/2)
  - VLESS+XHTTP в режимах auto/packet-up/stream-up/stream-one: query x_padding
    пробрасывается через query: '*': '*' (length:50 вижу в логе xray), Xray
    открывает downstream поток, но gateway не отдаёт response client-у даже
    заголовков, держит до 60+ секунд таймаута

  Какой именно транспорт/протокол у вас в работающей схеме за nginx? Если можно
  поделиться кусочком xray inbound + nginx location + openapi-спекой — спасли бы
  мне ещё пару часов отладки.
