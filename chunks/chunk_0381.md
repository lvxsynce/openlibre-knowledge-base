TOS RuStore vs. статья с Хабра

Что говорит TOS

Сбор данных и телеметрия - в TOS этого практически нет. Упоминается только Политика конфиденциальности (отдельный документ), на которую идёт ссылка. Сам TOS описывает только: платежи, регистрацию через VK ID, отзывы, запрет спама/вирусов. Никакой конкретики о том, что именно собирается с устройства.

Установка приложений - п. 4.5 говорит, что пользователь "соглашается получать push-уведомления об обновлении Продуктов... а также из иных магазинов приложений". То есть RuStore явно заявляет право трогать приложения из других сторов - но формулировка размытая, про тихую установку ни слова.

Отзывы - п. 4.6.3: пользователь безвозмездно, безусловно и безотзывно передаёт VK неисключительное право использовать его отзывы как угодно, включая передачу третьим лицам. Стандартная для рынка, но агрессивная формулировка.

Ответственность - п. 4.4: VK снимает с себя ответственность за продукты разработчиков. Пользователь сам разбирается с ними.

───

Что нашла статья (реверс APK)

Подсистема Radar - снимок местоположения каждые 2 минуты: GPS, сеть, Cell ID, MAC роутера, оператор SIM, VPN-флаг, заряд батареи. Хранится в SQLite до 15 дней, раз в 12 часов уходит на reef.vk-cdn.net. Привязано к userId. В TOS об этом - ноль слов.

Тихая установка - сервер может поставить любое приложение из каталога push-сообщением без согласия пользователя. Флаг SAK_MAX_MESSENGER_INSTALL уже использовался для установки MAX (государственного мессенджера без E2E). Проверки того, оформлял ли пользователь предзаказ, нет. В TOS об этом - ноль слов.

Список установленных приложений - при каждом запуске уходит на сервер VK (packageNames без версий, то есть не для проверки обновлений). Виден список банков, VPN, мессенджеров, конкурирующих сторов. В TOS - ноль слов.

Статистика использования - время в каждом приложении, частота, последнее использование уходит на api.rustore.ru/user-event-handler батчем раз в 12 часов. Привязка к userId + vkId + deviceId. В TOS - ноль слов.

Kaspersky SDK - встроенный антивирусный движок с KSN-телеметрией, inotify по медиапапкам. В TOS - ноль слов.

───

Итог

TOS написан так, чтобы не раскрывать ничего конкретного - всё отфутболено на Политику конфиденциальности. При этом реальное поведение приложения (GPS-трекинг каждые 2 мин, тихая установка любого APK с сервера, полная инвентаризация устройства) в TOS вообще не упомянуто ни в какой форме.

Юридически это выглядит как намеренное умолчание: пользователь технически "согласился" с чем-то, но что именно делает приложение - из публичных документов не следует. Классическая схема - согласие через неведение.
