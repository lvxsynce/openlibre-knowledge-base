Есть AI-шлюз AgentRouter, на котором стала доступна безлимитно gpt-6.1-sol круглосуточно и без ожидания (плюс по расписанию выдают квоты на claude-opus-5-5 и gpt-6-astra).
Условия по балансу:
• На старте дают $175 – $200. По ссылке еще +$50: https://agentrouter.org/register?aff=OI75
• За ежедневный вход через GitHub начисляют еще по $25 в день (если уже авторизованы со вчера — достаточно сделать выход + вход, чтобы сработал чекин).
Шлюз можно подключить к любым инструментам вроде Cursor, Claude Code или RooCode.
Сам я работаю в консоли через Pi в связке с плагином @madgagarin/pi-agentrouter. Плагин обеспечивает полностью бесшовную работу: гарантирует непрерывные цепочки рассуждений, стабилизирует сессии и удерживает кэш на 99.8% (тяжелый запрос с контекстом на 200k токенов обходится всего в ~$0.05, так что ежедневных начислений хватает с запасом).
Как быстро запустить в Pi:
1. Зайти напрямую или по ссылке через GitHub (аккаунту должно быть больше года).
2. В разделе Tokens нажать Add Token, обязательно выбрать нужные модели (gpt-6.1-sol, claude-opus-5-5 и т.д.) и скопировать созданный ключ sk-....
3. В Pi поставить плагин:
pi install @madgagarin/pi-agentrouter
4. Ввести ключ и проверить живые квоты:
/agentrouter key sk-... и /agentrouter check
Важно! тк это халява не шлите туда ни чего очень важного.
