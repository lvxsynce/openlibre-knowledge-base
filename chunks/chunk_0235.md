Стороннее приложение не может произвольно записывать данные в TEE само по себе. Вся запись данных контролируется Trusted Application (TA), который работает внутри TEE. Приложение обращается к TA через стандартные API (например, TEE Client API), но какие именно данные записывать — решает сам TA. То есть API позволяет передавать данные в TA, но само решение о том, что хранить, какие команды доступны и как их обрабатывать, принимает TA. Таким образом, стороннее приложение может инициировать операции, но не имеет контроля над тем, какие данные в итоге будут сохранены.
