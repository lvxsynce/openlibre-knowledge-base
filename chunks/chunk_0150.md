Да, с аккаунта физического лица выложить VPN-приложение в TestFlight (и далее в App Store) можно. Никакого обязательного требования оформлять юридическое лицо (ООО или ИП) для этого нет.
Вот что важно понимать при публикации от физлица:
• Отображение имени: В графе «Разработчик» будет написано ваше имя и фамилия (латиницей, как в загранпаспорте), а не название вашего сервиса или студии.
• Тот же функционал: Физлицу доступны те же API (NetworkExtension), что и компаниям. Никаких технических ограничений в коде не будет.
• Модерация: Apple будет проверять приложение так же строго. Для них важнее, чтобы сервис не нарушал правила конфиденциальности и использовал официальные системные методы для создания туннеля.
• География: В некоторых странах (например, в Китае) для публикации VPN нужны специальные лицензии, которые физлицу не выдают, но для большинства других регионов и для самого TestFlight это не проблема.
Резюме: Если аккаунт Apple Developer уже есть на ваше имя — можете смело загружать сборку. Запрета на категорию «VPN» для частных лиц не существует.
