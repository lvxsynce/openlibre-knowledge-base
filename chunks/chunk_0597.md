☀️ Дневной дайджест OLC
сообщения 242741-244542, время 2026-09-08 06:31 - 2026-09-09 06:22 UTC

Дополнительно учтены ветки: DNS/WhiteDNS/StormDNS/MasterDnsVPN, Девлог, Вопросы, Баги.
В ветках «Девлог», «Баги» и «Сервисы для обхода бс» новых сообщений за этот диапазон не было.

🔥 Главное
Главная техническая линия дня — глубокий разбор API Яндекс Телемоста: участник выложил hello-пакет к WebRTC Яндекса, списки из сотни служебных API и
фрагменты самописного движка поверх WebRTC. Вторая линия — последствия слива Durev VPN: слитую подписку забанили, список серверов удалён, в чат
продолжают приходить люди с нерабочими «780 днями». По провайдерскому фронту участники писали, что gRPC начал шейпиться на части операторов, и советовали
переезжать на xHTTP.

⠀
🛠 Телемост и API Яндекса
По сообщениям участника, который «разобрал Телемост в нулину»:
— найдено больше 100 служебных API Телемоста, доступных по открытому маршруту;
— выложен hello-пакет к WebRTC Яндекса (serviceName: telemost, credentials, sessionSecret) — по его словам, это прямой вход в срез Яндекса, но нужны
токены;
— показаны фрагменты «голума» — самописного движка поверх WebRTC (GoloomTransport и транспорт на datachannel);
— звучала версия, что при прямом коннекте с движком, минуя станции обработки Яндекса, пинг лучше и скорость выше, а «защиты нет вообще никакой»;
— основная нерешённая проблема: сессии и токены умирают каждые пару минут, в браузере это решается само, а вне браузера участник пока не решил;
— гонять через это трафик можно «только по одному»: пакеты мелкие, запросы ограничены — годится как экстренный канал, Telegram «с болью пойдёт»;
— также участник заявил, что нашёл способ обхода капчи Яндекса, и обдумывает статью на Хабр с полной картой служебных путей, директорий, тел запросов и
API.

В чат были выложены списки API вида POST /telemost_front/v2/telemost/conferences и далее (конференции, пиры, waiting-rooms, permissions-matrix), плюс
отдельный набор «мусорных» API мессенджера.

⠀
🛰 VLESS, gRPC, xHTTP и SNI
— Участник с VLESS+gRPC+Reality жаловался, что звонки в Discord работают плохо при высокой скорости. По ответам: gRPC сейчас шейпится на некоторых
операторах и сетях и вычисляется легко, есть смысл переезжать на xHTTP — за ним пока не охотятся, но, по ощущениям участников, начинают.
— У другого участника raw TLS не работает на мобильных данных (Мегафон). Совет был — xHTTP+Reality и просканировать своего провайдера: что у него висит,
то и ставить как SNI (на 3x-ui это делается автоматом).
— Отдельно заметили: связка хуже работает именно на ПК (Windows и Linux), на телефоне норм — звучала версия, что по ПК выдают какие-то паттерны.
— Подбирали SNI для серверов Timeweb, где участники массово выбивают машины с белым IP 188.225.x: предлагали hh.ru и api.oneme.ru — по словам участников,
домен лёгкий, «ничего не весит», ТСПУ его не палит.
— На Т2, по сообщению участника, обходник в последнее время «дохнет через раз».
— У одного из участников при БС провайдер режет скорость до 1-2 Мбит вообще на всё, на L3 остаётся максимум Telegram.
— Режимы БС отличаются: у кого-то БС не включают и VLESS/Hysteria2/Trojan работают, у кого-то в центре БС включены с ноября и не выключаются.
— HTTP-прокси на инфраструктуре reg.ru (194.67.121.102:8080), который летом работал в БС, уже лежит — ICMP не ходит. Есть ещё вариант с МТС СПб, но он
часто падает.
— Участник написал, что в начале сентября Яндекс Клауд убил его сервер с публичным IP из белого списка — он теперь ищет альтернативы.

⠀
🔥 Durev и последствия слива
— После слива подписки (~780 дней) список серверов Durev удалили, саму слитую подписку забанили.
— В чат продолжают приходить люди с «не работает Durev VPN на 780 дней, куда писать» — по сути ответ один: подписка мертва.
— По деталям слива прозвучало, что выгрузили сабскрипт с балансерами и отдали в base64; часть участников считает, что «это даже не слив, это серьёзный
VPN».
— Всплывал скрин кривого конфига «ДодикVPN», где SNI и адрес перепутаны местами.
— Кидали статью на Хабре про Яндекс Браузер (habr.com/ru/articles/1064698); спрашивали, как удалить его сертификат — в статье этого нет.

⠀
📱 Клиенты: olcbox под iOS, панели и olcrtc
— Под iOS olcbox живёт через TestFlight — ссылка: https://testflight.apple.com/join/bhgn2Cc2. По словам автора, билд собран на базе последних версий,
план — финальный апдейт в TestFlight и затем в App Store.
