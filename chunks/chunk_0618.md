Реально, спасибо за наводку. У меня в кадди было так:

domain {
    handle {
        root * /opt
        file_server
    }
}

Яша, вк и турбо с / открывали заглушку, а для бегета надо было явно /index.html
Добавил перед handle в кадди:
rewrite * /index.html
И так любой путь будет показывать заглушку

Но ток важно для бегета указывать в пути любое расширение файла, иначе также 403
